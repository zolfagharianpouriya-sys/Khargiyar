# خرج‌یار – نسخه آزمایشی ۱.۰ (Samsung / Android 16)

اپلیکیشن اندروید برای ثبت هزینه با گفتار فارسی، اعلان برداشت بانکی و گزارش هزینه‌ها.

## قابلیت‌ها
- ثبت هزینه با گفتار فارسی؛ نمونه: «۱۲۰ هزار تومان بنزین» یا «۱۲۰ تومن بنزین».
- ذخیره محلی در SQLite؛ داده‌ها روی گوشی می‌مانند.
- جمع هزینه امروز، هفته، ماه و سال.
- دریافت پیامک و تشخیص محافظه‌کارانه پیام‌های دارای نشانه برداشت/خرید/پرداخت.
- اعلان با لمس برای توضیح صوتی هزینه.
- سرویس foreground برای تشخیص تکان گوشی.

## نکات مهم مخصوص Android 16
- اندروید به برنامه اجازه نمی‌دهد در همه شرایط از پس‌زمینه بدون تعامل کاربر صفحه میکروفون را باز کند. پس از پیامک، اعلان فوری نشان داده می‌شود و با لمس آن ضبط/تشخیص گفتار آغاز می‌شود.
- برای شروع تشخیص تکان، کاربر باید از داخل برنامه سرویس را فعال کند. اندروید/One UI ممکن است برای ماندگاری سرویس، اجازه فعالیت پس‌زمینه یا عدم محدودیت باتری بخواهد.
- پیامک‌های چهار بانک ملی، ملت، کشاورزی و بلو از طریق متن پیامک بررسی می‌شوند؛ چون قالب پیامک بانک‌ها و واحد مبلغ ممکن است تغییر کند، قبل از استفاده مالی واقعی باید با نمونه پیامک هر حساب تست شود. پیامک‌های واریز، رمز پویا و مانده حساب عمداً نادیده گرفته می‌شوند.
- اگر پیامک مبلغ را با «ریال» مشخص کند، مبلغ به تومان تبدیل می‌شود. در صورت نبود واحد، مقدار بدون تبدیل ثبت می‌شود؛ این مورد باید با پیامک واقعی هر بانک اعتبارسنجی شود.
- تشخیص گفتار فارسی به سرویس گفتار نصب‌شده روی گوشی وابسته است.
- مجوز SMS برای نصب دستی درخواست می‌شود؛ انتشار در Google Play تابع محدودیت‌های سخت‌گیرانه مجوز پیامک است.

## ساخت APK در GitHub Actions بدون نصب Android Studio
1. محتوای پوشه `Khargiyar` را در یک مخزن GitHub جدید با شاخه `main` قرار بده.
2. به تب **Actions** برو و workflow با نام **Build Khargiyar APK** را اجرا کن.
3. پس از موفقیت، در همان اجرای workflow بخش **Artifacts** فایل `Khargiyar-debug-apk` را دریافت کن.
4. فایل `app-debug.apk` را روی گوشی نصب کن و مجوزهای لازم را بده.

## ساخت محلی
نیازمند JDK 17، Gradle 8.9 و Android SDK Platform 35 است:

```bash
gradle --no-daemon assembleDebug
```

خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## مواردی که باید پیش از استفاده روزمره آزمایش شوند
- نمونه پیامک واقعی برداشت از هر چهار بانک و اطمینان از تشخیص مبلغ درست.
- تبدیل ریال/تومان برای هر بانک.
- عملکرد سرویس تکان پس از قفل صفحه در One UI و تنظیمات باتری سامسونگ.
- دقت تشخیص گفتار فارسی و تفسیر عبارت‌های محاوره‌ای.
