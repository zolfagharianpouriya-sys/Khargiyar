# خرج‌یار — ثبت هزینه با تکان دادن گوشی

نسخه 1.1:
- Shake detection با شتاب‌سنج
- بوق و فعال شدن تشخیص گفتار
- تشخیص عبارت‌هایی مثل «200 هزار تومن پول بنزین»
- ذخیره مبلغ، عنوان، تاریخ و ساعت در Room
- جمع هزینه‌های امروز
- ویجت هزینه‌های امروز
- نمایش لیست هزینه‌ها

## ساخت
پروژه را در Android Studio باز کنید، Gradle Sync بزنید و Build > Build APKs را اجرا کنید.

## نکته مهم اندروید
برای تشخیص Shake وقتی برنامه در پس‌زمینه است، برنامه یک Foreground Service با اعلان دائمی اجرا می‌کند. در Android 13+ اجازه Notification و Microphone لازم است.

نسخه فعلی parser برای مبالغ عددی است (مثلاً 200 هزار، 347000، 2 میلیون). در نسخه بعدی می‌توان تشخیص کامل اعداد فارسیِ گفتاری مثل «دویست هزار» را اضافه کرد.

- تشخیص اعداد گفتاری فارسی مانند «دویست هزار تومن بنزین»
- گزارش امروز، هفته، ماه و سال
